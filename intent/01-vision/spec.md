# VRS Vision — Spec

This document specifies `vision.md` files. It builds on
[requirements.md](./requirements.md).

## Status

Draft.

## Structure

A `vision.md` uses these sections unless a smaller node has an obvious reason to
omit one:

```markdown
# <Topic> — Vision

## The Need

## The Vision

## What This Is Not

## Success Criteria
```

`The Need` may use problem language, opportunity language, or domain tension
language. The section is not required to be titled `The Problem`; the framing
should fit the topic without forcing implementation detail into the vision.

Success criteria are numbered and durable. If a criterion implies a mechanism,
move that mechanism to requirements or spec.
